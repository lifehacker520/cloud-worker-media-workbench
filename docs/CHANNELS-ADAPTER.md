# 视频号采集适配说明

## 当前实现

视频号加入监控中心的平台筛选和账号链接识别，支持：

- `channels.weixin.qq.com` 创作者页或作品管理页；
- `weixin.qq.com/sph/...` 单条视频号分享链接；
- `finder.video.qq.com/...` 作品链接。

视频号没有适合本项目直接轮询他人公开主页的稳定公开接口，因此桌面客户端会为视频号打开独立且持久化的 Electron 浏览器会话。用户在窗口内自行登录微信、打开创作者助手的作品列表或一条公开分享页，然后点击账号卡片的“补采”。采集器只读取浏览器页面已经展示的头像、昵称、标题、发布时间、封面、作品链接、播放/曝光/点赞/收藏/评论/分享等指标和最新评论，并写回本地工作台。监控中心会将视频号作为独立平台卡片展示，汇总已保存的作品快照；缺失指标显示为“—”。设置 → 服务连接 → 平台登录态可以重新打开会话或显式清除视频号登录态；客户端不会读取或导出 Cookie。

## 边界

- 这是 Beta 能力，不保证读取所有账号的完整历史作品；
- 网页模式不能调用本机微信会话，视频号补采需要桌面客户端；
- 登录态保存在本机按平台隔离的 Electron `persist:` 分区，客户端重启后可复用；登录是否有效仍以平台页面实际提示为准；
- 不读取或上传 Cookie，不绕过验证码、登录限制或平台安全机制；
- 单条分享链接适合作为验证入口，长期监控仍建议使用创作者页或作品列表页。

## 后续路线

优先补充页面状态识别、分页加载、手动“再次读取”和采集诊断；如后续获得官方授权，再评估使用官方数据接口替代浏览器会话。
