# S7-02 前置调研｜真实效果导向的技术选型（开源 + 商用 API）

- 日期：2026-09-11（实时联网调研）
- 负责人诉求：数字人口播效果与 TTS 语音效果要在市面上一流、真实；支持 20–30 条批量；开源与商用 API 都纳入
- 结论：**TTS 走商用 API（效果/成本/接入速度三优）；数字人视频走 HeyGem/Duix-Avatar 自托管云 GPU（开源天花板，6–8GB 显存即可）**

| **MiniMax 海螺** | 小红书"自来水"最佳，"听不出 AI" | ~$0.10/1K | REST，低 | **并列首选**：开箱自然度口碑最好，300+ 音色 + 克隆 |

## 3. 推荐组合

```text
TTS：豆包 或 MiniMax API（按量，中文顶级，当天接入）
  ↓ 音频
数字人：HeyGem/Duix-Avatar 自托管（云 4090 按量，整合包 6–8GB）
  ↓ 视频
模板合成：FFmpeg（已有底座）
```

- 效果：TTS 市面第一梯队 + 开源数字人天花板（被大量商用套壳验证）
- 成本：TTS 按字（一条口播几厘钱）+ GPU 按时（一次批量几十元）
- 批量：Worker 租约/重试已有，云 GPU 一晚 20–30 条
- 风险对冲：HeyGem 许可证（Apache 2.0 vs DUIX Community 两说）在部署时以 LICENSE 原文核对；商用 API（硅基/闪剪）作为效果不达标时的替代路径
