## 一、U1：轴徽章溢出修复（含两次尝试）

### 问题

`.dh-axis-badge`（结果卡三轴徽章）在 `#digital-human p01 @1024` 与 `@200%` 下各有 3 处横向溢出，文案为「未选择交付」。

### 根因

徽章继承 `.dh-badge` 的 `white-space: nowrap`，窄屏容器放不下 5 个汉字时无法收缩。

### 第一次尝试（失败）

```css
max-width: 100%;
white-space: normal;
word-break: keep-all;   /* ← 错误 */
```

**失败原因**：`word-break: keep-all` 对 CJK 的语义是「不允许在字符间断行」，恰好**禁止了我想要的换行**。改完复测，溢出仍是 3 处。

### 第二次尝试（成功）

```css
/* #view-digital-human .dh-axis-badge */
max-width: 100%;
white-space: normal;
overflow-wrap: anywhere;
line-height: 1.35;
```

**效果**：`@1024` 与 `@200%` 的溢出均降为 **0**；宽屏仍是单行（`line-height` 变化在单行下无视觉差异）。

**影响面控制**：只改这一个类。状态徽章（`.dh-badge` 本体与 `.dh-badge-*`）文案更短，仍保持 `nowrap`，不受影响。

## 三、探针的三次修正（方法论，值得留存）

F5-C4 报出的"12 处文字溢出"中，只有 6 处（DH 徽章）是真问题。探针本身有 3 个系统性误报，本轮逐一修正：

| # | 误报类型 | 现象 | 修正规则 |
|---|---|---|---|
| 1 | 屏幕阅读器元素 | `.sr-only`（monitor 7 处） | 排除 `classList.contains('sr-only')` |
| 2 | 行内元素 | `clientWidth` 恒为 0，必然"溢出" | 排除 `display: inline` |
| 3 | 已裁切元素 | 省略号截断（monitor 账号名）本就是**正确设计** | 排除 `overflow !== 'visible'` |

**修正后：14 个场景的文字溢出全部为 0。**

此外发现一处**时序抖动**：`#content @1280` 首次测得步进导航为 0（其余场景均为 5）。将导航后等待从 2.6s 延长到 3.2s 后恢复为 5，确认为渲染时序问题，非缺陷。
