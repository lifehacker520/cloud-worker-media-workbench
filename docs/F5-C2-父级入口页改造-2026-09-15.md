## 3. 保留的桥接逻辑

**只保留一条**，即任务要求的监控作品带入：

```
监控中心作品卡 [data-create-content-work]
  └─ app.js createContentTaskFromWork(fingerprint)          ← 保留
       ├─ 组装 prefill（title / workTitle / platforms / sourceUrl / sourceWorkFingerprint / sourceBrief）
       ├─ sessionStorage['cloud-worker-content-prefill']    ← 保留（key 三处一致）
       ├─ setView('digital-human')                          ← 改动点（原为 'content'）
       └─ dispatchEvent('content-work-prefill')             ← 保留
            ├─ content-workspace.js 监听 → 记录并展示带入卡  ← 保留
            └─ digital-human-workspace.js 监听 → dhGoToPage('p02') + 展示带入卡 ← 新增
```

| 桥接要素 | 位置 | 约束 |
|---|---|---|
| 会话键 | `cloud-worker-content-prefill` | 三处必须一致：`app.js` / `content-workspace.js:22` / `digital-human-workspace.js`（`DH_PREFILL_KEY`） |
| 带入卡 | `content-workspace.js` `prefillBlock()` | 仅展示，不创建任务 |
| 带入卡 | `digital-human-workspace.js` `dhWorkPrefillBlock()` | 仅展示，橙色系表示"待人工确认"，与真实数据蓝区分 |
| 授权边界 | 两处带入卡均写明 | 「监控来源是公开平台元数据，**不会自动视为已授权素材**」 |
| 清除 | `data-cw-clear-prefill` / `data-dh-prefill-clear` | 只清带入，不动任何生产数据 |

**桥接刻意不做的事**：不创建内容任务、不恢复旧表单、不自动授予素材授权、不在新中心新增「创建内容任务」能力（F5-C0 判定其归属存疑，未获产品确认）。
