## 6. 硬件结论

- **本机（M4/16GB，无 NVIDIA）不能直接运行**：Duix.Avatar、MuseTalk、LatentSync、VideoReTalking、EchoMimic V3、SadTalker（全部 NVIDIA/CUDA 优先或强制）。
- **本机可做**：FFmpeg/ffprobe 全部媒体底座；声音候选的本机可行性首验（MLX/MPS 路径，仓库已有 `mlx_audio_tts.py` wrapper）；Worker 协议与队列验证（fake adapter）。
- **必须的外部条件（不自行采购/切云，等负责人决策）**：一台 NVIDIA GPU 机器或云 GPU实例（建议 ≥24GB 显存、32GB 内存、Ubuntu 22.04 + Docker），用于部署 Duix.Avatar（模式 A）与 MuseTalk（模式 B）；通过既有 `XHS_MEDIA_WORKER_URL`（HTTP）或 command 桥接接入，客户端零改动。
- 声音候选若本机 MPS/MLX 验证通过，可先在**本机**完成 S7-02 的真实中文声音样片；若不通过，声音也并入外部 GPU Worker。
