## 3. 仍然缺失 / 未验证

1. **真实批次端到端 E2E**：草稿 → 建批次 → `/batches/:id/run` → `/results/items` → 验收 → 导出包，全链路需 AutoDL 实例**开机**（当前关机，避免计费）。
2. **N13 字幕自动切句**：现有 `burnSubtitles` 需外部提供时间轴；自动切句需接 ASR（未实现）。
3. **批量串行化的工程硬化**：当前 `maxConcurrency` 由常量控制，真实 GPU 并行争用会互相拖慢（已记录，未改）。
4. **发布链路与内容包的打通**：release-drafts 走 CE-23 任务节点，内容包（manifest）与之并存但未合并为单一路径——需产品确认以哪个为准。

## 4. 结论

第八阶段的目标「让真实输出能够逐条查看、人工判断、按版本重做、筛选并导出」在代码层面**已闭环**，其中 N20/N21/N22 的主体是既有实现（本阶段确认并复用），本阶段真正补齐的是：**真实连接器接入、逐条明细投影、内容包（含门禁）、批次执行入口、用量统计**。剩余唯一实质阻塞是**真实端到端验证需要云实例开机**。
